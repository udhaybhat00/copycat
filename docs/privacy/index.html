Privacy & data choices

Understand which Copycat features run locally, when configured providers receive data, and how activation works.

What this website uses

The website serves product information, guides, downloads, and a regional pricing estimate. It does not add advertising pixels, Google Analytics, or marketing tracking cookies. GitHub Pages serves the website and Netlify provides the regional-pricing endpoint. Both hosting providers may process ordinary request and security logs under their own policies.

Local and hosted processing in the app

Supported local speech models process recognition on your device. When you select a cloud speech provider, audio needed for that request is sent to the provider. Hosted answer models receive the question and relevant context for generation. Review your selected providers and app settings before using private material.

Resume and session content

Resume and job-description uploads can be used as reference material for answers. The app can save session transcripts and notes locally. Your chosen AI provider may receive the relevant context used for an answer. Local transcription does not imply that every feature uses only local processing.

Licensing and email

The activation service uses a device identifier and license status to establish a trial or device-bound access. It does not need your meeting audio, transcript, or AI-provider key. The Activate action opens an email draft; you choose whether to send the device details and purchase request to Udhay.

Pricing and external links

The pricing function uses the hosting platform’s country information to choose a currency display and requests a reference exchange rate for INR. Download links go to GitHub. Share controls open your device’s share sheet or copy a public link; the website does not automatically post to your social accounts.

Contact

For questions about Copycat data handling or licensing records, contact udhaybhat00@gmail.com. Do not include API keys, license keys, or private transcripts in a public GitHub issue.
